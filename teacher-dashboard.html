Setup Instructions (if student data isn't showing)

Your current database policies only let users see their own data. To let your account see students in your school, run these two things in Supabase SQL Editor:

1. Run the supabase-teacher-rls.sql file — this creates teacher-level read policies.

2. Promote your account to teacher:

-- Replace YOUR_USER_ID with your actual user ID from Supabase Auth
UPDATE profiles SET role = 'teacher' WHERE id = 'YOUR_USER_ID';

You can find your user ID in Supabase Dashboard → Authentication → Users. It's the UUID next to your email.
