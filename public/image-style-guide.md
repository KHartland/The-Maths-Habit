# The Maths Habit - Visual Style Guide

## Overview

A cohesive, modern educational visual style that feels engaging for teenagers while maintaining clarity for mathematical concepts.

### Core Aesthetic: Metallic Blue
The app uses a **polished metallic blue** as its signature look - professional, sophisticated, and timeless. This gradient treatment appears throughout:
- App UI (buttons, cards, headers)
- Diagram shapes and fills
- Icons and visual elements

**Metallic Gradient Recipe:**
- Highlight (top): `#8BA8D9`
- Base (middle): `#5B7FC7`
- Shadow (bottom): `#3D5A8A`

This gives a polished, 3D appearance that looks premium without being flashy or "vibe coded".

## App UI Styling

The metallic blue gradient should be used for:
- **Primary buttons** - metallic gradient fill with subtle hover state
- **Card headers** - gradient background for section titles
- **Progress indicators** - filled portions use metallic gradient
- **Active states** - selected items, current question markers
- **Icons** - key icons can use the gradient or solid base blue

Keep the UI clean with plenty of white space. The metallic blue provides visual interest without needing lots of competing colours.

**Background:** Clean white or very light grey (`#F8F9FA`)
**Cards/Containers:** White with subtle shadow
**Text:** Dark grey (`#374151`) for readability

## Two Image Categories

### Category A: Context Images (Realistic)
For questions with real-world scenarios: shopping, journeys, recipes, sports, buildings.

**Style characteristics:**
- Vibrant, high-quality 3D renders or photography style
- Warm, inviting lighting
- British context (£ signs, UK settings)
- Clean, uncluttered compositions
- Text/labels integrated naturally (price tags, signs, displays)
- Soft depth-of-field blur on backgrounds
- Modern, aspirational feel (like a good textbook or educational app)

**Examples:** Juice bottles on shelf, taxi with meter, cinema foyer, café table

---

### Category B: Diagram Images (Modern Clean)
For geometry, graphs, and mathematical representations.

**Style characteristics:**
- Clean white or very light grey background
- Lines in **Primary Blue** (`#4A90D9`) - NOT black
- Measurements/given values in **Warm Orange** (`#F59E0B`)
- Unknown values (?, x, y) in **Metallic Blue** (`#5B7FC7`)
- Shape fills use **metallic gradient** - polished 3D look with lighter top, darker bottom
- Angle markers in **Gold/Yellow** (`#D4A84B`) for visibility
- Subtle shadow or slight 3D effect for depth (not flat, not overly 3D)
- Rounded corners on labels and callout boxes
- Modern sans-serif font (Inter, Poppins, or similar)
- Grid lines in very light grey when needed
- Small icons or visual touches to add warmth

**Key differences from AQA style:**
| AQA Style | Our Style |
|-----------|-----------|
| Pure black lines | Primary Blue lines |
| No colour | Colour-coded elements |
| Stark white background | Soft off-white/light grey |
| Purely functional | Slight visual warmth |
| "Not drawn accurately" | Clean, but still not to scale |

## Typography

- **Labels:** Inter or Poppins, semi-bold, dark grey (`#374151`)
- **Measurements:** Same font, regular weight, orange (`#F59E0B`)
- **Variables:** Same font, italic, metallic blue (`#5B7FC7`)
- **Size labels:** (Small, Large, etc.) - friendly, rounded font

---

## Diagram Elements

### Shapes
- **Lines:** 2-3px stroke, Primary Blue or dark grey, slightly rounded ends
- **Shapes:** Dark outline with **metallic blue gradient fill** - lighter at top (#8BA8D9), base colour in middle (#5B7FC7), darker at bottom (#3D5A8A). This creates a polished, 3D spherical/cylindrical look.
- **Right angles:** Small yellow/gold square marker in corner (like the reference diagrams)
- **Equal marks:** Small tick marks in blue

### Arrows & Vectors
- Clean arrow heads, blue
- Dashed lines for construction/hidden edges (blue, dashed)

### Points & Vertices
- Small filled circles (blue) for points
- Labels (A, B, C) positioned clearly outside shape

### Grids & Axes
- Light grey grid lines (`#E5E7EB`)
- Darker grey axes (`#6B7280`)
- Arrow heads on axes
- Clear number labels

### Annotations
- Callout boxes with rounded corners
- Light background with coloured border
- Measurement arrows with orange colour

---

## Consistency Rules

1. **Same palette everywhere** - Context images can be vibrant but should feel warm (oranges, teals, natural colours). Diagrams use the defined palette.

2. **Same font family** - All text in images uses the same modern sans-serif.

3. **Same label style** - Whether it's a price tag on a juice bottle or a measurement on a triangle, labels have consistent styling.

4. **Matching iconography** - If using icons (checkmarks, question marks), use the same style throughout.

5. **Similar lighting/mood** - Context images all have warm, inviting lighting. Diagrams all have clean, bright feel.

## Examples by Question Type

### Price/Shopping Questions
- Realistic product photography style
- Clean shelf/counter backgrounds
- Price tags with consistent design (rounded rectangle, white background, clear font)
- Products clearly labelled

### Journey/Speed Questions
- Vehicles shown at slight angle, dynamic feel
- Distance markers or signs integrated naturally
- Speedometers/displays shown clearly
- British roads/settings

### Building/Construction Questions
- Clean architectural style
- Measurement annotations in orange
- Slight 3D perspective
- Realistic materials but simplified

### Geometry Questions
- Modern diagram style with dark outlines
- **Metallic blue gradient fills** for shapes (polished 3D look)
- Gold/yellow angle markers for visibility
- Orange measurements, metallic blue unknowns
- Clean cream/off-white background with subtle border

### Graph Questions
- Light grey grid
- Blue axes with arrow heads
- Coloured lines for different functions
- Key points marked with dots and labels

### Probability Questions
- Clean tree diagrams or Venn diagrams
- Colour-coded branches/regions
- Clear probability labels
- Friendly, accessible style

### Statistics Questions
- Modern chart/graph style
- Consistent colour scheme
- Clear labels and legends
- Slight 3D depth on bar charts (optional)

## Image Specifications

- **Format:** PNG with transparency OR JPG for photos
- **Resolution:** 1024×1024 or 1024×768 (landscape)
- **File size:** Optimised for web (<500KB)
- **Naming:** `{category}_{code}_{description}.png`
  - `context_N1_juice-bottles.png`
  - `diagram_G19_ladder-wall.png`

---

## Quality Checklist

Before using any image:

- [ ] Colours match the brand palette
- [ ] Text is readable and uses correct font style
- [ ] Measurements are clearly visible
- [ ] Image feels consistent with other images in the set
- [ ] No jarring elements that break the style
- [ ] British context (£, UK settings) where relevant
- [ ] Clean, uncluttered composition
- [ ] Appropriate for teenage audience
